# Project Statement

The **Student Performance Tracker and Academic Risk Predictor** is a Python project that helps summarize a student’s academic performance. It collects the student’s name, attendance percentage, and marks in Maths, Science, and English. The program calculates the total and average marks, assigns a grade, and estimates an academic risk level based on the student’s average and attendance. It then displays a suggestion based on the predicted risk level.

This project demonstrates Python input handling, input validation, arithmetic operations, conditional statements, and formatted output. It is intended for educational purposes and provides a basic indicator rather than a formal assessment of academic progress.
